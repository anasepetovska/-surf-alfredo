# Surf Alfredo

One-page static website for **Surf Alfredo**: surf lessons with José Alfredo Cascante Sánchez at Esterillos Este, Costa Rica.

- Book: WhatsApp [+506 6197-3363](https://wa.me/50661973363)
- Instagram: [@josealfredocascantesanchez](https://www.instagram.com/josealfredocascantesanchez/)

## Structure

- `index.html`: the whole site (no build step)
- `assets/`: logo, photo and short looping videos
- `.github/workflows/pages.yml`: deploys to GitHub Pages on every push to `main`

## Editing

Change `index.html` and push to `main`. The site redeploys automatically.
